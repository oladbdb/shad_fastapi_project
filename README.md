# shad_fastapi_project

## Описание

Учебное приложение на FastAPI для работы с книгами и продавцами (с авторизацией).

Сделано:
- **Книги (`Book`)**: CRUD‑эндпоинты, валидация входных/выходных данных через Pydantic, хранение в PostgreSQL через SQLAlchemy.
- **Продавцы (`Seller`)**: CRUD‑эндпоинты, связь «один ко многим» с книгами, каскадное удаление книг при удалении продавца, скрытие пароля из всех ответов.
- **Авторизация по JWT**: эндпоинт `POST /api/v1/token` (email + пароль продавца → JWT), защита токеном:
  - `GET /api/v1/seller/{seller_id}`
  - `POST /api/v1/books/`
  - `PUT /api/v1/books/{book_id}`

## Как запустить

1. Собрать и запустить контейнеры:
   ```bash
   docker compose up --build
   ```
2. API будет доступно по адресу `http://localhost:<APP_PORT>` (по умолчанию `8008`).

## Тестировать через `api_tests.http`

1. В блоке «Создать продавца» выполнить запрос `POST /api/v1/seller/` — будет создан продавец с email/паролем.
2. Выполнить запрос `POST /api/v1/token` и скопировать полученный `access_token`.
3. В самом верху файла в строке
   ```http
   @token = PASTE_JWT_TOKEN_HERE
   ```
   заменить `PASTE_JWT_TOKEN_HERE` на скопированный токен.
4. Дальше можно запускать остальные запросы:
   - создание книги `POST /api/v1/books/`,
   - обновление книги `PUT /api/v1/books/1`,
   - получение продавца по id `GET /api/v1/seller/1`
